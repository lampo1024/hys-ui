# 0.1.1 验证记录

验证环境：Windows、Node.js 24、Vue 3.5、Chrome 与 Firefox，2026-11-07 至 2026-11-08。此记录说明组件库的验证范围。

## 构建与包接入

- 组件导出、独立路由、交互示例与 API 参考通过完整性检查。
- 组件与公开类型统一使用 Hys 前缀，组件包不依赖平台数据或 Vue Router。
- 发布白名单校验仅允许构建产物、README、许可证、更新记录和包元信息。
- 仓库外的最小 Vue 项目安装实际 npm 压缩包，通过公共类型检查与构建，确认单份 Vue、无路由依赖、未使用的 DataGrid 不进入应用脚本。
- 宿主页面的标题、按钮及背景样式保持原样；浮层和对话框正确继承主题，响应式切换主题生效。
- npm audit 对全部依赖及生产依赖的检查均为 0 项已知漏洞。
- 已从公开 npm 安装 `hys-ui@0.1.0`，其 SHA-512 完整性与测试过的压缩包一致；安装后再次通过类型、构建、主题、浮层和 Mention 定位的验证。

## 行为回归

`npm test` 的行为测试覆盖按钮保护、输入组合事件、数字精度和边界、选择器、表单同步/异步规则和重置、树形选择、上传约束、日期禁用、键盘操作、焦点恢复、浮层清理、虚拟渲染、主题继承、异步关闭竞争，以及不传可选受控参数时的消息提示和 Popover 行为。新增检查包括消息队列与计时、抽屉方向/全屏、自定义复选/单选、权限批量选择、远程选择名称缓存、异步取消、表单字段关联、滑块步进和面板键盘调整，以及分页模型同步、通知禁用、搜索输入法、命令高亮、引导、富文本取消、文件区域键盘操作、组织数据归一与复合字段焦点。

Chrome 与 Firefox 均检查组件文档页面的加载、源码展开、运行错误与整页溢出。窄屏布局以 390 × 844 检查，并特别检查表格内部横向滚动。

浏览器重点交互包括：

- 页面 KeepAlive 保留输入状态。
- 年/月快速定位、返回日期视图、自定义颜色面板。
- 穿梭框拖动、排序列表手柄拖动和键盘排序。
- DataGrid 共用筛选行、清空与关闭、表头悬停无抖动/背景、列拖动排序；释放动画处理数量有上限。
- 10,000 行虚拟表格保持有限渲染，窄屏滚动后可查看最右侧列。
- Mention 候选跟随 @、多行与滚动更新位置，选择后保留后文，窄屏自动避让。
- 浮层继承主题、对话框焦点约束与关闭后滚动恢复。
- 轻提示显示位置、剩余时间暂停/恢复、队列合并/更新/关闭，以及页面离开时的清理。
- 抽屉四方向的进入和退出、全屏大小与滚动恢复。
- 甘特图月视图填满容器、窗口调整及拖动日期换算。
- 下拉选项单行、自适应/等宽浮层、远程搜索与失败恢复、自定义内容，以及窄屏边界。
- 示例配置分组、控件对齐与重置；源码格式化/高亮、工具栏复制、键盘折叠和移动端布局。Chrome 检查真实剪贴板；Firefox 检查复制调用与反馈。

## 复现

运行 `npm ci` 后执行 `npm run check:release`，完成类型检查、两项构建、行为测试、完整性检查、打包及外部接入验证。使用 `npm run dev:docs` 启动文档，浏览器回归脚本保存在 `scripts/browser-*.cjs`，可通过 Playwright CLI 的 `run-code --filename` 执行。

浏览器截图与本地检查日志位于被 Git 忽略的 `output/playwright` 和 `artifacts`。当前面向 Vue 3.5+ 浏览器应用，验证范围不包含 SSR/Nuxt。
