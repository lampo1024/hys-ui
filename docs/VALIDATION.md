# 0.1.0 验证记录

验证环境：Windows、Node.js 24、Vue 3.5、Chrome 与 Firefox，2026-11-07 至 2026-11-08。此记录说明首版的验证范围；组件的高级能力边界见 [组件对标清单](COMPONENT_PARITY.md)。

## 构建与包接入

- 组件库、独立文档和 ProjectFlow 均通过 TypeScript 检查与生产构建。
- 69 个命名导出、69 个独立路由、177 个示例场景通过完整性检查。
- 源码、声明、文档与业务引用已迁移为 Hys 前缀，组件包不依赖平台数据或 Vue Router。
- 发布白名单校验仅允许构建产物、README、许可证、更新记录和包元信息。
- 仓库外的最小 Vue 项目安装实际 npm 压缩包，通过公共类型检查与构建，确认单份 Vue、无路由依赖、未使用的 DataGrid 不进入应用脚本。
- 宿主页面的标题、按钮及背景样式保持原样；浮层和对话框正确继承主题，响应式切换主题生效。
- npm audit 对全部依赖及生产依赖的检查均为 0 项已知漏洞。

## 行为回归

`npm test` 的 35 项测试覆盖按钮保护、输入组合事件、数字精度和边界、选择器、表单同步/异步规则和重置、树形选择、上传约束、日期禁用、键盘操作、焦点恢复、浮层清理、虚拟渲染、主题继承、异步关闭竞争，以及不传可选受控参数时的消息提示和 Popover 行为。

Chrome 与 Firefox 均检查全部 69 个文档页面的加载、源码展开、运行错误与整页溢出。窄屏布局以 390 × 844 检查，并特别检查表格内部横向滚动。

浏览器重点交互包括：

- 页面 KeepAlive 保留输入状态。
- 年/月快速定位、返回日期视图、自定义颜色面板。
- 穿梭框拖动、排序列表手柄拖动和键盘排序。
- DataGrid 共用筛选行、清空与关闭、表头悬停无抖动/背景、列拖动排序；释放动画处理数量有上限。
- 10,000 行虚拟表格保持有限渲染，窄屏滚动后可查看最右侧列。
- Mention 候选跟随 @、多行与滚动更新位置，选择后保留后文，窄屏自动避让。
- 浮层继承主题、对话框焦点约束与关闭后滚动恢复。
- ProjectFlow 10 个业务路由可访问，页面切换后保留搜索条件。

## 复现

运行 `npm ci` 后执行 `npm run check:release`，完成类型检查、两项构建、行为测试、完整性检查、打包及外部接入验证。使用 `npm run dev:docs` 启动文档，浏览器回归脚本保存在 `scripts/browser-*.cjs`，可通过 Playwright CLI 的 `run-code --filename` 执行。

浏览器截图与本地检查日志位于被 Git 忽略的 `output/playwright` 和 `artifacts`。验证通过不代表所有浏览器、所有宿主样式或服务端适配均已覆盖；首版面向 Vue 3.5+ 浏览器应用，SSR/Nuxt、国际化和对标清单列出的复杂高级能力留待后续版本。
