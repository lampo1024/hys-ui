# ProjectFlow V9 甘特图组件

独立组件：`src/components/HysGantt/HysGantt.vue`。已集成到任务管理 → 甘特图。

## 功能
- 日/周/月时间密度切换、跨月时间轴、周末底色、今天参考线与定位今天
- 日期驱动的任务条、完成进度、状态/负责人、任务选中、依赖关系连线（通过 dependencies 指定）
- `editable` 开启鼠标拖动任务、两端调整日期；Alt+左右方向键按天移动任务
- 受控数据：`items` 输入，`update:items` 输出完整新数组，`change` 输出修改后的任务，`open` 输出点击的任务
- 非法日期任务自动隐藏并在页脚提示；使用 UTC 日历日运算，减少夏令时引起的错位

## 接入说明
业务演示数据只有截止日期，任务开始日期暂由预估工时推算。真实业务必须存储 `start` 和 `end`，并通过 API 持久化修改。依赖关系需要后端提供。
