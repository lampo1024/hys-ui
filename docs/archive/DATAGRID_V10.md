# V10 高级表格

新增 HysDataGrid，不破坏原 HysTable 与 HysVirtualTable API。支持列宽拖拽、列顺序拖拽及按钮调整、列显隐、列宽本地持久化、文本筛选、单列排序、搜索、分页、跨页选择、CSV 导出、自定义单元格插槽与三种密度。

演示入口：左侧导航「高级数据表格」。完整 API 参见 `docs/COMPONENT_LIBRARY.md`。

已知限制：无服务端数据模式；不支持固定列、多列排序、动态行高虚拟滚动；移动端使用按钮而非触屏拖放调整列顺序。建议对真实业务数据接入前做浏览器、键盘与数据量测试。
